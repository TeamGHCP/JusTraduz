# Ensaio cronometrado

## Meta

Apresentar o fluxo completo em até 10 minutos, deixando 3 a 5 minutos para perguntas.

## Roteiro de 10 minutos

| Tempo | Bloco | O que mostrar | Frase de apoio |
|---:|---|---|---|
| 0:00-0:45 | Problema | Landing page | "O problema é que muita gente recebe documento jurídico e não entende o risco nem o próximo passo." |
| 0:45-1:30 | Solução | Fluxo da landing | "O JusTraduz combina IA, profissional validado e organização do atendimento." |
| 1:30-2:50 | Cliente | Dashboard + documento analisado | "A IA transforma o documento em linguagem simples, com aviso claro de limitação." |
| 2:50-3:50 | Ajuda | Solicitação do cliente | "Quando a dúvida exige cuidado, o usuário abre uma solicitação." |
| 3:50-5:10 | Advogado | Dashboard, caso, tarefa e chat | "O profissional recebe fila priorizada e trabalha no caso." |
| 5:10-6:10 | Agenda | Atendimento marcado | "O fluxo não termina na IA; ele organiza o atendimento humano." |
| 6:10-8:30 | Admin | Métricas, OAB, documentos, auditoria | "O admin prova maturidade operacional: validação, risco e rastreabilidade." |
| 8:30-9:20 | Segurança | Explicar controles | "Há consentimento de IA, autorização por perfil, storage protegido e auditoria." |
| 9:20-10:00 | Fechamento | Banca/comparação | "Diferente de um CRUD comum, este projeto resolve uma dor real e sensível." |

## Roteiro de 5 minutos

1. Problema e landing.
2. Documento analisado.
3. Solicitação + chat.
4. Dashboard admin.
5. Segurança e fechamento.

## Checklist de ensaio

- [ ] Abrir navegador já na landing.
- [ ] Ter credenciais demo abertas em uma aba separada.
- [ ] Login cliente testado.
- [ ] Documento demo abre sem erro.
- [ ] Admin abre sem erro.
- [ ] Auditoria contém registros.
- [ ] Cronômetro rodado pelo menos duas vezes.
- [ ] Versão curta treinada para caso a banca corte tempo.

## Corte se faltar tempo

Se o tempo apertar, não mostre:

- cadastro completo;
- troca de senha;
- todas as páginas admin;
- todos os filtros.

Priorize:

1. Documento + IA.
2. Atendimento humano.
3. Admin + auditoria.
