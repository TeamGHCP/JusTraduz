# Documentacao do JusTraduz

A documentacao ativa fica centralizada aqui para evitar varias versoes da verdade.

## Documentos ativos

- `MELHORIAS_PARA_100.md`: mapa historico de maturidade e entregaveis P0/P1/P2/P3.
- `PRODUCAO_P0.md`: checklist operacional de producao, health check, backup e restore.
- `LGPD_E_REVISAO_JURIDICA_P0.md`: processo LGPD, exportacao, exclusao, incidentes e operadores.
- `P1_OPERACIONAL.md`: DataJud/CNJ, OCR, antimalware, storage privado, fila, limites, e-mail e auditoria.
- `REGISTRO_REVISAO_JURIDICA.md`: modelo para registrar aprovacao juridica externa.
- `apache-justraduz-production.conf`: modelo Apache/HTTPS/HSTS.
- `O_QUE_FALTA_AGORA.md`: pendencias reais restantes depois da entrega P0/P1.
